CLOSET — E-Commerce API & Backend
A robust RESTful API built for CLOSET , a full-stack e-commerce web application for fashion and clothing. This backend powers user authentication, product catalog management, shopping cart operations, image uploads, and admin management.

---
Tech Stack

-Runtime Environment: [Node.js](https://nodejs.org/)
- Framework: [Express.js](https://expressjs.com/)
- Language: JavaScript (Node.js)
- Database: [PostgreSQL](https://www.postgresql.org/)
- ORM: [Prisma ORM](https://www.prisma.io/)
- Authentication: JSON Web Tokens (JWT) & Password Hashing (bcrypt)
- Cloud Deployment: [Railway](https://railway.app/)

---
Features

- Authentication & Authorization:  Secure JWT-based registration, login, and role-based access control (User vs. Admin).
- Product Management: Full CRUD operations for clothing items, categories, sizes, colors, and stock inventory.
- Cart & Orders: Endpoint integration for handling user shopping carts and checkout processes.
- Image Handling: Multipart form-data handling for product media uploads.
- Database ORM: Schema management and type-safe database queries via Prisma.
